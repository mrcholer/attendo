# Xattendo V6.1

This branch integrates the customized V6.1 dashboard with the upstream period-aware backend. The compatible dashboard controller and theme selector are retained; the new upstream hourly lock and period time data are displayed in Lock history and Attendance. The server's PWA static asset allowlist is already enabled.

Update an existing clone with `git pull --ff-only origin master`, restart the local server, and hard refresh the browser. Keep your local attendance records and credentials outside Git.

V6.1 includes outside-click search dismissal, settings input sizing, daily goal validation, and keyboard navigation. Attendance forecasting and offline records are estimates and available-history summaries, not official attendance totals.
